# Final Fantasy I · Корнелия — три реализации вертикального среза

Одно и то же задание — играбельный вертикальный срез начала **Final Fantasy I**
(город Корнелия, замок, северный мост, Святилище Хаоса и Гарланд) — выполнено три
раза независимо, тремя разными агентами. Все проекты на **Godot 4.7**, целиком 3D,
без внешних библиотек и загружаемых ассетов: вся геометрия собирается кодом.

## Проекты

| Папка | Версия | Что внутри |
| --- | --- | --- |
| [`ff-1-sol`](ff-1-sol/) | основная, самая полная | 3D-срез с городом, услугами (гостиница, три лавки, клиника), пошаговыми боями, Святилищем Хаоса с ключом и двумя этажами, спасением Сары, финальной сценой постройки моста и экраном «ДЕМО ЗАВЕРШЕНО». Есть `Play.cmd` (запуск одним кликом) и `Test.ps1` (прогон тестов). Документация — в `docs/`. |
| [`ff-1-ds`](ff-1-ds/) | альтернативная | Тот же срез с акцентом на процедурную геометрию города (`world/town_builder.gd`), отдельными сборщиками локаций и набором тестовых сцен в `tests/`. Скриншот-инструменты — в `tools/`. Описание — в `README.md`. |
| [`ff-1-kimi`](ff-1-kimi/) | альтернативная, компактная | Минимальная по количеству файлов версия: 10 скриптов, один JSON с данными игры. Описание — в `agent_info.txt`. |

## Запуск

1. Установите **Godot 4.7** (проверено на 4.7.2).
2. Откройте `project.godot` нужного проекта.
3. Нажмите **F5**.

Для `ff-1-sol` можно просто дважды щёлкнуть `Play.cmd` — он сам находит Godot,
импортирует ресурсы и запускает игру.

Управление: `WASD` / стрелки — шаг по клеткам, `E` — действие, `I` — снаряжение,
`M` / `Tab` — карта, `Esc` — закрыть окно / пауза.

## Что не входит в репозиторий

- `.godot/` — кэш импорта, кэш шейдеров и настройки редактора. Создаётся заново
  при первом открытии проекта, в git не нужен (см. `.gitignore`).
- Скриншоты и логи прогонов. Они остаются в рабочих папках проектов, но в
  репозиторий не копировались: это документация, а не исходники.
  Из-за этого в `ff-1-ds/README.md` и `ff-1-sol/README.md` остались ссылки на
  отсутствующие изображения — текст и таблицы при этом читаются нормально.
